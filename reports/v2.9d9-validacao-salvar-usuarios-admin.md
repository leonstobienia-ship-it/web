# V2.9D9 - Validação do botão Salvar em Usuários

- Data: 2026-06-11
- Escopo: correção do bloqueio indevido do botão Salvar na página Usuários.
- Pacote SPFx: 1.0.0.9

## Problema observado

Na página Usuários, com a ação Criar usuário e campos obrigatórios preenchidos, o botão Salvar permanecia desabilitado.

A mensagem de pré-validação exibida após o ajuste de feedback indicou:

`Acao exige usuario ativo com Administrador do Sistema e PodeAdministrarConfiguracoes=true.`

## Correção aplicada

- A página Usuários passou a exibir mensagem curta com o motivo de bloqueio do Salvar.
- Ao selecionar Criar usuário, o formulário passa a limpar dados herdados do usuário selecionado.
- A autorização administrativa V2.9C foi ajustada para aceitar o perfil ativo/selecionado Administrador do Sistema como autorização administrativa efetiva, sem exigir cumulativamente o campo PodeAdministrarConfiguracoes do cadastro do executor.
- O repositório SharePoint manteve o segundo portão de validação, agora alinhado à mesma regra de perfil administrativo ativo.
