# V2.9D11 - Recuperação do perfil Administrador do Sistema

- Data: 2026-06-11
- Escopo: evitar bloqueio de acesso administrativo após alteração de perfis do próprio usuário.
- Pacote SPFx: 1.0.0.11

## Problema

Após adicionar múltiplos perfis ao usuário Leon, o seletor de perfil passou a exibir apenas Diretoria e Campo / Engenharia, impedindo selecionar Administrador do Sistema.

## Causa técnica tratada

- O parser de `PerfisAdicionais` estava preparado principalmente para texto separado por `;`.
- Em cenários reais do SharePoint, o campo pode chegar como coleção/array ou `{ results: [...] }`.
- Valores com rótulos alternativos da interface também precisavam ser reconhecidos, como `Campo / Engenharia`, `Compras / Financeiro` e `Planejamento / Aprovação`.

## Correção aplicada

- `PerfisAdicionais` agora aceita:
  - string separada por `;`;
  - array;
  - objeto com `results`;
  - rótulos de escolha usados na interface e no SharePoint.
- `getPerfisAutorizados` adiciona `AdministradorSistema` como opção de recuperação quando o usuário possui `PodeAdministrarConfiguracoes=true`.
- Isso evita o lockout administrativo caso o campo de perfis adicionais venha incompleto ou em formato diferente.
