# V2.8E - Pagina Dedicada Sistema ENAC

Data: 2026-06-09

Branch: `dev/v2.3-sharepoint-integracao`

## Objetivo

Preparar o Sistema ENAC para abrir em pagina dedicada tipo aplicativo, reduzindo a aparencia de pagina comum do SharePoint e mantendo a webpart como experiencia principal.

Codex nao conectou ao SharePoint, nao publicou pacote, nao instalou app, nao alterou tenant/listas/permissoes/dados, nao executou escrita operacional e nao iniciou Power Automate.

## Decisao Tecnica

A webpart `Sistema ENAC` passa a suportar:

- `SharePointWebPart`;
- `SharePointFullPage`.

O suporte a `SharePointFullPage` permite usar a webpart em uma Single Part App Page / `SingleWebPartAppPage`.

Essa abordagem reduz a dependencia visual de listas, menus e pagina comum, mas nao elimina necessariamente toda a barra global do Microsoft 365 ou elementos padrao do SharePoint em todos os contextos.

## Pagina De Homologacao

Nome recomendado:

`Sistema ENAC - Homologação`

URL esperada:

`/sites/Equipe.Obras/SitePages/Sistema-ENAC-Homologacao.aspx`

Pagina final futura:

`/sites/Equipe.Obras/SitePages/Sistema-ENAC.aspx`

A V2.8E prepara homologacao, nao producao ampla.

## Criacao Manual Recomendada

1. Publicar o pacote SPFx gerado localmente no App Catalog, em rodada manual autorizada.
2. Ir para o site `https://enaccombr.sharepoint.com/sites/Equipe.Obras`.
3. Criar a pagina `Sistema ENAC - Homologação`.
4. Adicionar a webpart `Sistema ENAC`.
5. Configurar a pagina como Single Part App Page / `SingleWebPartAppPage`, preferencialmente pelo script manual `scripts/sharepoint/16-criar-pagina-sistema-enac-app-page.ps1`.
6. Publicar a pagina.
7. Validar com usuario final sem permissao de edicao.

## Roteiro Com Script

O script preparado para execucao manual posterior e:

`scripts/sharepoint/16-criar-pagina-sistema-enac-app-page.ps1`

Dry-run recomendado:

```powershell
pwsh -File ".\scripts\sharepoint\16-criar-pagina-sistema-enac-app-page.ps1" `
  -Tenant "enaccombr.onmicrosoft.com" `
  -ClientId "<CLIENT-ID-AUTORIZADO>" `
  -AuthMode "DeviceLogin" `
  -PageName "Sistema-ENAC-Homologacao.aspx"
```

Execucao real somente por Leon/Admin, com confirmacao:

```powershell
pwsh -File ".\scripts\sharepoint\16-criar-pagina-sistema-enac-app-page.ps1" `
  -Tenant "enaccombr.onmicrosoft.com" `
  -ClientId "<CLIENT-ID-AUTORIZADO>" `
  -AuthMode "DeviceLogin" `
  -PageName "Sistema-ENAC-Homologacao.aspx" `
  -Execute `
  -ConfirmacaoPagina "CONFIRMAR-PAGINA-APP-SISTEMA-ENAC-V2.8E"
```

O script nao deve alterar listas, dados operacionais ou Power Automate.

## Navegacao

Nao tentar remover o chrome global do SharePoint com hacks.

Recomendacoes:

- usar Single Part App Page;
- colocar link direto no Teams;
- colocar link direto no menu principal da empresa;
- remover permissao de edicao da pagina para usuarios finais;
- usar a navegacao interna do Sistema ENAC como navegacao principal;
- avaliar manualmente `?env=WebView` apenas como teste de visualizacao, sem depender disso como solucao oficial.
