# V2.9D - Separacao de usuarios e perfis administrativos

## Objetivo

Separar a administracao V2.9C em telas mais claras:

- `Usuários`: cadastro e atualizacao basica de usuario.
- `Perfis`: configuracao de perfil principal, perfis adicionais e permissoes operacionais.
- `Alçadas`: permanece separada para regras de aprovacao.
- `Auditoria`: permanece separada para historico administrativo.

## Alteracoes aplicadas

### Menu administrativo

Foi adicionada a entrada `Perfis` ao menu visivel somente para usuario ativo com perfil `AdministradorSistema`.

### Pagina Usuarios

A pagina `Usuários` passou a focar em:

- acao `Atualizar usuário` ou `Criar usuário`;
- usuario alvo, quando aplicavel;
- nome completo;
- conta Microsoft 365 ID ou e-mail;
- e-mail corporativo;
- ID interno;
- perfil principal;
- status ativo/inativo;
- cargo/funcao;
- observacoes;
- justificativa;
- confirmacao final;
- pre-validacao e payload previsto.

Campos tecnicos de permissao foram removidos desta pagina.

### Pagina Perfis

A nova pagina `Perfis` permite configurar usuarios existentes com:

- usuario;
- perfil principal;
- perfis adicionais;
- permissoes operacionais;
- aplicacao do padrao de permissoes do perfil principal;
- justificativa;
- confirmacao final;
- pre-validacao e payload previsto.

## Limite sobre novos perfis

Criar uma nova categoria de perfil ainda nao foi implementado como escrita real, porque os perfis atuais sao choices/modelos fixos no codigo e no SharePoint. Para permitir novos perfis dinamicos, sera necessaria uma etapa propria de schema, provavelmente com lista de configuracao de perfis e revisao das regras de acesso.

## Segurança preservada

- A escrita continua restrita a V2.9C.
- Continua exigindo flags no Property Pane.
- Continua exigindo usuario executor ativo com `AdministradorSistema` e `PodeAdministrarConfiguracoes`.
- Continua exigindo confirmacao final `CONFIRMAR-ESCRITA-ADMINISTRATIVA-V2.9C-ENAC`.
- Continua registrando historico administrativo.
- Nao houve Power Automate.
- Nao houve alteracao em `src/prototype/app.js`.
- Nao houve alteracao no backup V2.2.
