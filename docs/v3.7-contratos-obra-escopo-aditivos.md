# V3.7 - Contratos de Obra, Escopo Comercial e Aditivos

## Objetivo

Implementar a base contratual local das obras da ENAC, vinculando contrato, escopo comercial, aditivos, medicoes e pedidos internos de faturamento em PostgreSQL local.

A V3.7 nao emite NFS-e real, nao integra prefeitura, nao gera boleto, nao integra banco, nao executa pagamento, nao cria CNAB, nao usa SharePoint real, nao usa Entra real, nao usa Power Automate e nao usa `DELETE` fisico.

## Escopo entregue

- Migration `017_contratos_obra_escopo_aditivos_v37.sql`.
- Nova tabela `contratos_obra`.
- Nova tabela `contratos_obra_itens`.
- Nova tabela `contratos_obra_aditivos`.
- Evolucao de `medicoes_obra` com vinculo opcional a contrato/aditivo.
- Evolucao de `pedidos_faturamento` com vinculo opcional a contrato/aditivo.
- Endpoints REST para contratos, itens e aditivos.
- Aprovacao de aditivos por alcada local.
- Tela `Contratos de Obra`.
- Ajuste da tela `Medições e Faturamento` para selecionar contrato/aditivo.
- Smoke `npm.cmd run smoke:contratos-obra`.
- Auditoria em `auditoria_eventos`.

## Fluxos

Contrato:

```text
RASCUNHO -> ATIVO
ATIVO -> SUSPENSO -> ATIVO
ATIVO | SUSPENSO -> ENCERRADO
RASCUNHO | ATIVO | SUSPENSO -> CANCELADO
```

Aditivo:

```text
RASCUNHO -> SUBMETIDO -> APROVADO
SUBMETIDO -> REPROVADO
RASCUNHO | SUBMETIDO -> CANCELADO
```

## Regras

- Contrato deve estar vinculado a empresa, cliente e obra.
- Contrato pode estar vinculado a centro de custo.
- Contrato precisa ter valor original maior que zero.
- Contrato so pode ser ativado com ao menos um item ativo.
- Itens de escopo so podem ser alterados no contrato em `RASCUNHO`.
- Item nao e removido fisicamente; usa status `INATIVO`.
- Aditivo aprovado soma em `valor_aditivos` e atualiza `valor_total_contratado`.
- Aditivo nao aprovado nao libera medicao/faturamento.
- Se uma obra possui contrato ativo, a medicao deve referenciar contrato ativo compativel.
- Medicao nao pode exceder o saldo contratual total.
- Pedido de faturamento herda e valida o contrato/aditivo da medicao.
- Aprovacao de aditivo usa escopo local `contratos-obra`.
- Todas as transicoes relevantes registram auditoria.

## Limites

- Sem emissao real de NFS-e.
- Sem integracao com prefeitura.
- Sem boleto real.
- Sem cobranca bancaria.
- Sem integracao bancaria.
- Sem pagamento.
- Sem CNAB.
- Sem SharePoint real.
- Sem Entra real.
- Sem Power Automate.
- Sem `DELETE` fisico.
