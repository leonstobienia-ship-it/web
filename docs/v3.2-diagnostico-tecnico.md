## Diagnostico

O produto ja possui uma base funcional relevante em SPFx/React e um portal Vite para apresentacao/entrada web. A principal limitacao tecnica e a concentracao de responsabilidades em poucos arquivos grandes, especialmente `EnacSistema.tsx` e `web/src/main.tsx`.

Para a V3.2, a decisao mais segura e criar a fundacao modular sem mover telas existentes. Isso reduz risco de regressao no sistema atual e prepara a proxima fase para extrair componentes, paginas, servicos e features com testes menores.

## Decisao V3.2

- Criar estrutura modular no frontend sem redesenhar a UI.
- Criar backend Node.js separado em `server/`.
- Criar migration PostgreSQL inicial em `database/`.
- Criar tipos TypeScript ERP iniciais.
- Documentar limites de execucao: migration nao aplicada em producao, backend sem conexao obrigatoria com banco real, SharePoint preservado como documental/operacional atual.
