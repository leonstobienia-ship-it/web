# V2.7A - Transicoes de Status do Fluxo de Compras

Data: 2026-06-08

## Fonte

Status desejados vieram das regras de negocio do MVP. Choices reais devem ser confirmados em teste no tenant antes de liberar uso operacional amplo. A V2.7A nao altera choices no SharePoint.

## Status de referencia

| Ordem | Status de referencia | Observacao |
| --- | --- | --- |
| 1 | Rascunho / Nova | Entrada inicial ou item recem-criado. |
| 2 | Em conferencia | Complementacao tecnica/operacional. |
| 3 | Aguardando cotacao | Fila para cotacoes. |
| 4 | Em cotacao | Cotacoes em andamento. |
| 5 | Cotada | Proposta recomendada pronta. |
| 6 | Aguardando aprovacao | Alçada/snapshot aplicavel. |
| 7 | Aprovada | Compra aprovada. |
| 8 | Reprovada | Encerramento por reprovacao. |
| 9 | Pedido emitido | Pedido criado por Compras/Financeiro. |
| 10 | NF vinculada | NF/boleto/dados vinculados. |
| 11 | Pagamento programado | Programacao financeira criada. |
| 12 | Concluida | Pagamento/processo encerrado. |
| 13 | Cancelada | Encerramento por cancelamento. |

## Transicoes preparadas no codigo

| Acao | Status origem aceitos | Status destino previsto |
| --- | --- | --- |
| Criar requisicao | Nao aplicavel | Aguardando cotacao |
| Atualizar requisicao | Nova/Rascunho, Aguardando cotacao, Em cotacao, Cotada, Aguardando aprovacao | Conforme payload validado |
| Criar snapshot/aprovar | Cotada, Aguardando aprovacao | Aguardando aprovacao ou Aprovada |
| Criar pedido | Aprovada, Aprovada para compra | Pedido emitido |
| Vincular NF | Pedido emitido, Compra realizada / Aguardando NF | NF vinculada |
| Programar pagamento | NF vinculada, Aguardando programacao financeira | Pagamento programado |
| Registrar historico | Qualquer status | Nao altera status por si so |
