## Execucao Manual Futura

A execucao so pode ocorrer se a pre-validacao especifica passar.

Antes da escrita, o metodo revalida o item por GET e confirma item, marcador, status e snapshot vazio.

Escritas permitidas nesta acao:

- POST em `ENAC Snapshots Regras`;
- MERGE/POST override no item configurado da Lista 02 para preencher `SnapshotAprovacaoCompra`;
- POST em `ENAC Historico Configuracoes` para historico operacional.

Escritas proibidas:

- DELETE;
- PATCH;
- alterar item diferente do configurado;
- alterar status para aprovada;
- criar pedido;
- criar NF;
- programar pagamento;
- iniciar Power Automate.

## Idempotencia

Se o item ja possuir `SnapshotAprovacaoCompra`:

- nao criar novo snapshot;
- nao alterar vinculo;
- bloquear o botao de criacao;
- exibir o snapshot existente;
- tratar como estado de validacao existente, sem escrita.
