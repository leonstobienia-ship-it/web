# V3.18A-D - Correcoes de Homologacao: Navegacao e Acessos

## Objetivo

A V3.18A-D consolida ajustes operacionais levantados na homologacao assistida, sem alterar regras de negocio, regras financeiras, alcadas, endpoints ou migrations.

O pacote corrige a experiencia de uso em quatro frentes:

- topbar com usuario e perfil ativo visiveis;
- menu lateral recolhivel por grupos;
- Administracao de Acessos mais facil de encontrar;
- identificacao da tela antiga como `Legado - consulta`.

## Escopo entregue

### V3.18A - Topbar

- A topbar passou a exibir `Usuario`, `Perfil ativo` e `Navegar para tela`.
- O perfil ativo e um contexto visual local para homologacao.
- O seletor de navegacao continua disponivel, mas nao aparece mais como controle principal chamado `Modulo`.

### V3.18B - Menu recolhivel

- O menu foi reorganizado em grupos recolhiveis.
- O grupo ativo permanece aberto para manter o item atual visivel.
- A estrutura separa `Administracao` e `Legado` dos grupos operacionais.

### V3.18C - Administracao de Acessos

- O item do menu agora se chama `Administracao de Acessos`.
- A tela passa a apresentar o cabecalho `Usuarios, Perfis, Escopos e Alcadas`.
- Foram adicionados cards de resumo para usuarios, perfis, escopos e alcadas.
- As abas existentes foram preservadas e continuam usando os endpoints locais ja validados.

### V3.18D - Polimento operacional

- A chamada antiga `Sistema atual` foi removida da navegacao principal.
- O legado ficou identificado como consulta controlada.
- O guia operacional foi atualizado para refletir a nova estrutura.

## Limites

Nao houve:

- migration nova;
- modulo backend novo;
- endpoint novo;
- alteracao de alcadas;
- alteracao de permissoes;
- pagamento funcional;
- baixa nova;
- CNAB;
- banco real;
- integracao bancaria;
- NFS-e real;
- prefeitura;
- boleto;
- SharePoint/Graph/Entra/Power Automate real;
- `DELETE` fisico.
