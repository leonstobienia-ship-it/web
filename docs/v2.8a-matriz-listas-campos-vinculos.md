## Impacto Dos Vinculos Textuais

Os vinculos textuais permitiram validar o fluxo sem alterar schema do tenant nesta rodada.

Antes de producao ampla, os vinculos textuais devem ser reavaliados porque:

- podem aceitar digitacao divergente;
- podem criar duplicidade em caso de numero repetido;
- dificultam navegacao entre listas;
- reduzem garantias de integridade referencial;
- exigem filtros e pre-validacoes mais defensivos no codigo.

## Plano De Correcao Pre-Producao

Sem provisionar nesta rodada, recomenda-se estudar:

1. `Lista 03.Pedido -> Lista 02.Requisicao` por lookup.
2. `Lista 04.NF -> Lista 03.Pedido` por lookup.
3. `Lista 10.Programacao -> Lista 04.NF` por lookup.
4. Regras de unicidade para numeros textuais mantidos como chave humana.
5. Migracao assistida dos registros de teste para preservar rastreabilidade.
