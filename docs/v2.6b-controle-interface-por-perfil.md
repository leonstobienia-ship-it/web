## Relacao com currentUserPerfil

`currentUserPerfil` deve controlar visibilidade e ergonomia da interface, mas a decisao de seguranca final deve depender de:

- usuario autenticado via Microsoft 365;
- cadastro em `ENAC Usuarios Perfis`;
- grupos/permissoes SharePoint;
- estado do processo;
- regra de alçada/snapshot vigente.

## Limitacoes do client-side

- Usuario pode tentar acessar rotas/estados internos.
- Dados carregados no cliente podem ser inspecionados pelo navegador.
- Botao oculto nao equivale a permissao negada.
- A API SharePoint deve negar escrita quando o usuario nao tiver permissao real.
