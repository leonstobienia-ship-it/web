## Riscos

- Gerar scaffold diretamente na raiz pode sobrescrever ou reorganizar arquivos existentes se a operação não for controlada.
- O código atual da webpart usa imports SPFx como `@microsoft/sp-http`, mas essas dependências ainda não estão instaladas.
- O repositório `SharePointEnacRepository.ts` ainda contém pontos a revisar em rodada posterior, incluindo referências antigas a listas lógicas como `ENAC Solicitacoes`, enquanto o mapeamento validado usa `Lista 02 — Requisições de Compra`.
- A webpart atual ainda mistura dados simulados no componente com repositório real preparado. A V2.4A não deve mudar a interface nem ligar dados reais sem plano específico.
- Qualquer build SPFx pode revelar erros TypeScript que hoje não aparecem porque não há toolchain instalada.
- Power Automate, permissões finas e limpeza dos dados `V2.3B-TESTE` continuam fora desta rodada.

## Plano técnico de build

1. Criar uma cópia controlada ou branch específica antes de qualquer scaffold.
2. Gerar scaffold SPFx mínimo com o mesmo nome lógico da solução, preferencialmente em pasta temporária fora da raiz do projeto.
3. Comparar os arquivos gerados pelo Yeoman com a estrutura atual antes de copiar qualquer arquivo.
4. Trazer para a raiz somente os arquivos de scaffold necessários:
   - `package.json`
   - `package-lock.json`
   - `tsconfig.json`
   - `gulpfile.js`
   - `.yo-rc.json`
   - `config/*`
   - manifests e arquivos de entrada da webpart, se ainda ausentes.
5. Preservar `src/prototype/app.js`, `src/prototype/index.html`, `src/prototype/styles.css` e `backups/v2.2-interface-homologada`.
6. Adaptar o scaffold para apontar para `src/webparts/enacSistema` sem redesenhar a interface.
7. Instalar dependências com npm apenas após revisar `package.json`.
8. Executar build local SPFx:
   - `npm install`
   - `npx gulp clean`
   - `npx gulp build`
9. Corrigir apenas erros necessários para compilar, sem integrar lógica nova com SharePoint e sem alterar interface visual.
10. Registrar resultados e pendências antes de qualquer teste em tenant.
