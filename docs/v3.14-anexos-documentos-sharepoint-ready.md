# V3.14 - Anexos e Documentos preparados para SharePoint

## Objetivo

Implementar a base local de documentos e anexos do ERP ENAC, registrando apenas metadados e referencias mock para uma futura integracao documental com SharePoint.

A V3.14 nao envia arquivos, nao baixa arquivos, nao chama Microsoft Graph e nao usa SharePoint real.

## Escopo entregue

- Migration incremental `024_anexos_documentos_sharepoint_ready_v314.sql`.
- Nova tabela `documentos_anexos`.
- Endpoints REST em `/documentos`.
- Tela `Documentos e Anexos`.
- Smoke `npm.cmd run smoke:documentos`.
- Auditoria em `auditoria_eventos` para criar, editar, substituir e inativar referencias.
- Documentacao e checklist da etapa.

## Entidades documentaveis

Tipos aceitos em `entidade_tipo`:

- `cliente`;
- `fornecedor`;
- `obra`;
- `contrato_obra`;
- `aditivo`;
- `orcamento`;
- `solicitacao_compra`;
- `cotacao`;
- `pedido_compra`;
- `nota_fiscal_entrada`;
- `conta_pagar`;
- `programacao_pagamento`;
- `baixa_manual`;
- `medicao`;
- `pedido_faturamento`;
- `risco_pendencia`;
- `tarefa`;
- `auditoria`.

Cada criacao valida o tipo, o UUID e a existencia da entidade de origem.

## Tipos de documento

- `CONTRATO`;
- `ADITIVO`;
- `NF`;
- `BOLETO_REFERENCIA`;
- `COMPROVANTE_REFERENCIA`;
- `MEDICAO`;
- `FATURAMENTO`;
- `ORCAMENTO`;
- `PROPOSTA`;
- `COTACAO`;
- `PEDIDO`;
- `FOTO_OBRA`;
- `RELATORIO`;
- `OUTROS`.

`BOLETO_REFERENCIA` e `COMPROVANTE_REFERENCIA` sao apenas referencias documentais. Nao ha boleto real, pagamento real ou integracao bancaria.

## Status

- `ATIVO`;
- `INATIVO`;
- `SUBSTITUIDO`;
- `PENDENTE_ENVIO_FUTURO`;
- `ERRO_REFERENCIA`.

Inativacao e substituicao sao logicas. Nao existe `DELETE`.

## Endpoints

```http
GET /documentos
GET /documentos/:id
GET /documentos/entidade/:entidadeTipo/:entidadeId
POST /documentos
PATCH /documentos/:id
PATCH /documentos/:id/inativar
PATCH /documentos/:id/substituir
GET /documentos/tipos
GET /documentos/status
```

Nao existem endpoints de upload, download, SharePoint real, Graph, Power Automate, pagamento, baixa, CNAB, NFS-e, prefeitura ou boleto.

## Campos SharePoint mock

Campos reservados para integracao futura:

- `sharepoint_site_id_mock`;
- `sharepoint_drive_id_mock`;
- `sharepoint_item_id_mock`;
- `url_mock`;
- `referencia_local_mock`.

Eles nao acionam integracao real. Sao strings locais para rastrear a referencia planejada.

## Limites

- Sem SharePoint real.
- Sem upload real externo.
- Sem Microsoft Graph real.
- Sem Entra real.
- Sem Power Automate.
- Sem armazenamento de binario pesado no banco.
- Sem pagamento.
- Sem baixa nova.
- Sem CNAB.
- Sem banco real.
- Sem NFS-e real.
- Sem prefeitura.
- Sem boleto real.
- Sem `DELETE` fisico.

## Roadmap futuro

Uma etapa V4.x podera implementar integracao real com SharePoint usando Microsoft Graph, app registration propria, escopos aprovados, controle de permissao, upload versionado, reconciliacao de metadados e auditoria de chamadas externas. Essa integracao deve ser autorizada explicitamente antes de qualquer escrita externa.
