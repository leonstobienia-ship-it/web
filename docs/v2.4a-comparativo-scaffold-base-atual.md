## Compatibilidade de nomenclatura

O scaffold temporário gerou o mesmo nome técnico de webpart usado pela base atual:

- pasta: `enacSistema`
- componente: `EnacSistema`
- classe webpart: `EnacSistemaWebPart`
- alias no manifest: `EnacSistemaWebPart`

Isso reduz risco de migração, pois não há divergência de casing ou troca de pasta entre o scaffold e o código existente.

## Diferenças entre componentes

`components/EnacSistema.tsx` da base atual:

- contém a interface operacional ENAC usada como referência da webpart;
- possui dados simulados e fluxo visual próprios do MVP;
- usa `IEnacSistemaProps` definido no próprio arquivo;
- exporta `function EnacSistema(props: IEnacSistemaProps): JSX.Element`;
- importa `models.ts` e `EnacSistema.module.scss`;
- não deve ser sobrescrito nesta etapa.

`components/EnacSistema.tsx` do scaffold:

- é o componente React padrão do generator;
- importa imagens `welcome-dark.png` e `welcome-light.png`;
- usa `@microsoft/sp-lodash-subset`;
- espera props `description`, `isDarkTheme`, `environmentMessage`, `hasTeamsContext` e `userDisplayName`;
- exporta uma classe default `EnacSistema`;
- deve ser usado apenas como referência estrutural, não como substituto visual.

## Necessidades de adequação

Antes de copiar arquivos do scaffold para a raiz, será necessário:

- criar ou adaptar `EnacSistemaWebPart.ts` para renderizar o componente atual sem alterar sua interface visual;
- decidir se `IEnacSistemaProps.ts` será usado ou se o contrato de props atual será mantido/adaptado;
- garantir que `SharePointEnacRepository.ts` compile com as dependências SPFx, especialmente `@microsoft/sp-http`;
- revisar `EnacSistemaWebPart.manifest.json` para remover ou manter hosts Teams;
- revisar `skipFeatureDeployment` em `.yo-rc.json` e `config/package-solution.json`;
- decidir se os assets padrão `welcome-*` e `teams/*` serão descartados;
- preservar `models.ts` e `services/SharePointEnacRepository.ts`;
- não alterar `src/prototype/*` nem `backups/v2.2-interface-homologada/*`.

## Riscos identificados

- Copiar o componente padrão apagaria o trabalho visual e funcional da ENAC.
- O manifest gerado inclui hosts Teams, apesar de Teams não estar no escopo desta rodada.
- O scaffold usa `skipFeatureDeployment=true`; isso precisa ser validado contra a estratégia de implantação.
- O package gerado não inclui `@microsoft/sp-http`, embora o repositório atual use esse pacote.
- A primeira compilação poderá revelar incompatibilidades no TSX atual, pois ainda não existe build SPFx na raiz.
