# V3.3A - PostgreSQL Local

## Objetivo

Validar a persistencia local do ERP ENAC em PostgreSQL, sem producao, sem SharePoint, sem Entra e sem automacoes.

## Escopo entregue

- `docker-compose.yml` com PostgreSQL 16 local.
- `.env.example` com variaveis de desenvolvimento.
- Backend com pool PostgreSQL via `pg`.
- Protecao para permitir apenas `enac_erp_dev` em `localhost`, `127.0.0.1` ou `::1`.
- `GET /health` preservado.
- `GET /health/db` criado para validar conexao local.
- Scripts `npm run migrate` e `npm run seed` no backend.
- Endpoints GET somente leitura:
  - `/empresas`
  - `/usuarios`
  - `/clientes`
  - `/fornecedores`
  - `/obras`
  - `/centros-custo`

## Como subir PostgreSQL local

Na raiz do repositorio:

```powershell
Copy-Item .env.example .env
docker compose up -d postgres
docker compose ps
```

O banco local esperado e:

- database: `enac_erp_dev`
- user: `enac_erp_dev`
- host: `127.0.0.1`
- port: `5432`

## Como rodar migration e seed

```powershell
cd server
npm install
npm run migrate
npm run seed
```

A seed cria registros marcados com `DEV_LOCAL_V3_3A`.

## Como rodar a API

```powershell
cd server
npm run build
npm start
```

## Como testar

```powershell
Invoke-RestMethod http://127.0.0.1:3333/health
Invoke-RestMethod http://127.0.0.1:3333/health/db
Invoke-RestMethod http://127.0.0.1:3333/empresas

Invoke-RestMethod http://127.0.0.1:3333/obras
```

## Bloqueio no ambiente Codex desta execucao

Durante a execucao da V3.3A neste ambiente, o comando `docker` nao estava disponivel no PATH. Por isso, a configuracao foi criada e o backend foi compilado, mas a subida real do container, migration, seed e testes de endpoints com dados dependem de execucao em maquina com Docker instalado.

## Garantias de seguranca

- `.env` continua ignorado no Git.
- `.env.example` contem apenas credenciais locais de desenvolvimento.
- A API bloqueia `DATABASE_URL` fora de banco local `enac_erp_dev`.
- Nenhuma escrita SharePoint foi executada.
- Nenhuma permissao Entra foi alterada.
- Nenhuma automacao foi criada.
- Nenhum banco de producao foi acessado.
