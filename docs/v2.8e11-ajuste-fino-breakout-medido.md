# V2.8E11 - Ajuste fino do breakout medido

## Contexto

A V2.8E10 validou a estrategia do breakout medido: o sistema finalmente esticou e o painel passou a ocupar a largura do navegador. O ajuste remanescente era um pequeno excesso lateral, com leve overflow horizontal.

## Causa

A formula da V2.8E10 usava a largura bruta do viewport:

```ts
const viewportWidth = window.innerWidth || document.documentElement.clientWidth || rect.width;
const measuredLeft = Math.max(0, Math.round(rect.left));

el.style.setProperty('--enac-breakout-left', `${measuredLeft}px`);
el.style.setProperty('--enac-viewport-width', `${Math.round(viewportWidth)}px`);
```

Como o CSS desloca o wrapper para a esquerda com `margin-left: calc(-1 * var(--enac-breakout-left))`, usar `viewportWidth` inteiro podia ultrapassar a lateral direita. Na pratica, a largura util precisa descontar o deslocamento medido e um pequeno gutter de seguranca.

## Solucao aplicada

A V2.8E11 manteve o breakout medido, mas passou a calcular a largura segura:

```ts
const viewportWidth = window.innerWidth || document.documentElement.clientWidth || rect.width;
const measuredLeft = Math.max(0, Math.round(rect.left));
const safetyGap = 16;
const safeViewportWidth = Math.max(320, Math.round(viewportWidth - measuredLeft - safetyGap));

el.style.setProperty('--enac-breakout-left', `${measuredLeft}px`);
el.style.setProperty('--enac-viewport-width', `${safeViewportWidth}px`);
```

Formula:

`largura util = viewportWidth - measuredLeft - 16px`

O `safetyGap` inicial adotado foi `16px`, para compensar scrollbar vertical, padding/margem do canvas e arredondamento de pixels. Se ainda houver pequeno overflow em algum navegador, o gap podera ser aumentado para `24px` em rodada futura.

## CSS preservado

O CSS da `.viewport` continua usando variaveis locais:

- `width: var(--enac-viewport-width)`;
- `max-width: var(--enac-viewport-width)`;
- `margin-left: calc(-1 * var(--enac-breakout-left))`;
- `box-sizing: border-box`;
- `overflow-x: hidden`.

Nao foi reintroduzido `100vw` bruto, margem fixa `calc(50% - 50vw)`, `left` negativo fixo ou `transform` negativo.
