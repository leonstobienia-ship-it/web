# V3.5F - Conferencia Financeira Final Pre-Baixa

## Objetivo

A V3.5F cria a conferencia financeira final de Programacoes de Pagamento ja `LIBERADA`, preparando a programacao para uma futura etapa de baixa manual sem executar pagamento, sem baixar Conta a Pagar e sem integracao bancaria.

## Escopo implementado

- Status de conferencia em `programacoes_pagamento`:
  - `PENDENTE_CONFERENCIA`;
  - `CONFERIDA`;
  - `BLOQUEADA_CONFERENCIA`;
  - `DEVOLVIDA`.
- Historico em `programacoes_pagamento_conferencias`.
- Checklist financeiro com fornecedor, documento fiscal, valor, vencimento, obra, centro de custo e forma prevista.
- Observacao obrigatoria quando houver ressalva.
- Registro de conferente, data/hora, valor total, quantidade de contas, status anterior/novo e motivo de bloqueio.
- Auditoria em `auditoria_eventos`.
- Tela de Programacao de Pagamento com status de conferencia, checklist e acoes de conferir/devolver.
- Smoke `smoke:conferencia-financeira`.

## Endpoints

```text
PATCH /programacoes-pagamento/:id/conferir-financeiro
PATCH /programacoes-pagamento/:id/devolver-conferencia
GET   /programacoes-pagamento/:id/conferencias
```

## Regras de bloqueio

A conferencia financeira e bloqueada quando:

- a programacao nao esta `LIBERADA`;
- a programacao esta cancelada ou reprovada;
- a programacao nao possui itens;
- existe conta inativa ou cancelada;
- existe divergencia pendente;
- existe conta sem aprovacao interna concluida;
- o usuario nao possui escopo ativo para conferencia.

## Garantias negativas

A V3.5F nao implementa:

- pagamento;
- baixa;
- status `PAGA`;
- endpoint `/pagar`;
- endpoint `/baixar`;
- endpoint `/executar-pagamento`;
- endpoint `/gerar-cnab`;
- integracao bancaria;
- CNAB;
- SharePoint real;
- Microsoft Entra real;
- Power Automate;
- `DELETE` fisico.
