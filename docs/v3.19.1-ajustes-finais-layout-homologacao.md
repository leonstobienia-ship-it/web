# V3.19.1 - Ajustes Finais de Layout para Homologacao

## Objetivo

A V3.19.1 aplica ajustes visuais finais para deixar o ERP ENAC pronto para homologacao pratica com a equipe.

Esta etapa e curta, visual e segura. Nao cria funcionalidade nova, nao altera regra de negocio e nao altera backend.

## Escopo

### Menu lateral

- Removido o texto `Sistema ENAC` abaixo do logo oficial no menu lateral.
- Mantido o texto `ERP operacional local`.
- Reposicionado o subtitulo para ficar alinhado ao bloco visual do logo.
- Refinado o bloco superior da sidebar com menos ruido visual.
- Preservada a imagem oficial do logo, sem fundo branco, sem card, sem distorcao e sem URL externa.

### Sidebar

- Sidebar permanece grafite escura.
- Grupos continuam separados por area: Operacao, Compras, Financeiro, Obras, Gestao, Administracao e Base ERP.
- Cada grupo preserva icone, titulo, subtitulo curto e seta discreta.
- Cada item preserva icone, label e marcador de perfil/area discreto.
- Item ativo usa destaque vermelho ENAC com fundo discreto.
- Nao ha textos auxiliares de abrir/recolher.
- Nao ha retorno do legado visual no menu.

### Alinhamento de cards

Foi reforcado o padrao global de grids e cards:

- containers de cards usam `align-items: stretch`;
- cards em grid usam `height: 100%`;
- cards usam composicao vertical com `display: flex`, `flex-direction: column` e `justify-content: space-between`;
- no mobile os cards voltam a altura automatica e empilham naturalmente.

Telas contempladas pelo padrao:

- Dashboard Executivo;
- Relatorios Financeiros;
- Documentos e Anexos;
- Central de Tarefas;
- Riscos e Pendencias;
- Contas a Pagar;
- Programacoes de Pagamento;
- Medicoes;
- Notas Fiscais de Entrada;
- Administracao/Acessos.

## Backend, migrations e endpoints

- Backend alterado: nao.
- Migration criada: nao.
- Endpoint criado: nao.
- Regra de negocio alterada: nao.

## Restricoes mantidas

A V3.19.1 nao implementa:

- pagamento real;
- baixa nova;
- CNAB;
- banco real;
- boleto real;
- NFS-e real;
- prefeitura;
- SharePoint real;
- Microsoft Graph real;
- Entra real;
- Power Automate real;
- upload externo real;
- `DELETE` fisico.
