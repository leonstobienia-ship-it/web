# V2.6A - Escrita controlada de snapshot pela webpart

Data: 2026-06-05

Branch: `dev/v2.3-sharepoint-integracao`

Commit base: `1015031 docs: registrar validacao pagina publicada readonly v2.5b`

## Objetivo

Preparar a primeira escrita controlada da webpart SPFx em SharePoint, limitada a teste manual futuro com dados marcados como `V2.3B-TESTE` ou `V2.6A-TESTE`.

Codex nao conectou ao SharePoint, nao publicou pacote, nao instalou app, nao alterou tenant, listas, permissoes ou dados e nao iniciou Power Automate.

## Modelo de seguranca

A escrita permanece desabilitada por padrao.

Travas obrigatorias implementadas:

- `escritaTesteHabilitada` padrao `false`;
- `modoEscritaTeste` padrao `false`;
- acao manual explicita do usuario;
- confirmacao textual obrigatoria: `TESTAR-ESCRITA-V2.6A-ENAC`;
- item alvo deve conter marcador de teste no `Title`;
- marcadores aceitos: `V2.3B-TESTE` ou `V2.6A-TESTE`;
- nao executar se `origemDadosEfetiva` nao for SharePoint;
- nao executar se `repository` nao existir;
- nao executar se item nao for localizado;
- nao executar se alcada aplicavel nao for resolvida;
- nao executar se aprovador base ativo nao for localizado;
- nao vincular se `SnapshotAprovacaoCompra` ja existir, salvo validacao idempotente;
- e-mails de aprovador nao sao gravados no snapshot de teste pela webpart;
- logs de teste ficam restritos a retorno tecnico da acao, sem e-mails reais.

## Escritas REST previstas

As escritas existem apenas nos metodos de teste:

- `spHttpClient.post` em `ENAC Snapshots Regras` para criar snapshot;
- `spHttpClient.post` com `X-HTTP-Method: MERGE` na Lista 02 para preencher `SnapshotAprovacaoCompra`;
- `spHttpClient.post` em `ENAC Historico Configuracoes` para registrar auditoria tecnica.

Nao ha `PATCH`, `DELETE` ou chamada de escrita automatica.

## Interface

A acao de teste fica oculta no pacote padrao.

Ela so aparece em `AdminHistorico` quando todas as condicoes abaixo forem verdadeiras:

- perfil atual `AdministradorSistema`;
- `escritaTesteHabilitada=true`;
- `modoEscritaTeste=true`;
- item, valor, marcador e confirmacao configurados;
- origem efetiva SharePoint carregada.

No pacote gerado nesta rodada, `EnacSistemaWebPart.ts` passa `escritaTesteHabilitada=false` e `modoEscritaTeste=false`.

## Riscos

- A criacao real depende de permissao de escrita no tenant e deve ser testada apenas por Leon em pagina restrita.
- O item alvo precisa conter marcador de teste no `Title`; caso contrario a escrita sera bloqueada.
- O campo `TipoSolicitacao` usado para resolver alcada fica configurado pela chamada de teste; nesta preparacao, a interface usa `Material` quando a acao for habilitada.
- Se o snapshot for criado e o vinculo falhar, o rollback manual deve tratar apenas o item de teste.
- Permissoes finas de listas ainda nao representam a governanca final.

## Rollback manual futuro

Somente se autorizado e apenas em dados de teste:

- remover `SnapshotAprovacaoCompra` do item de teste da Lista 02;
- excluir snapshot `SNAP-V2.6A-TESTE-*` se ele tiver sido criado exclusivamente para o teste;
- registrar a ocorrencia no historico administrativo;
- nunca alterar dados reais operacionais.
