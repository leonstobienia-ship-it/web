# V3.0b - Persistencia controlada de requisicao web

## Objetivo

Preparar a versao web para gravar uma nova requisicao de compra na lista real `Lista 02 — Requisições de Compra`, mantendo a operacao bloqueada por padrao.

## Escopo implementado

- Leitura das obras reais da `Lista 01 - Controle de Obras ENAC` por GUID.
- Uso do ID real da obra como lookup `ObraId` na criacao da requisicao.
- Criacao controlada de item na Lista 02 com marcador `V3.0B-WEB-TESTE`.
- Status inicial `Recebida`, compatível com os choices validados.
- Registro de auditoria em `ENAC Historico Configuracoes` quando a criacao da requisicao for concluida.
- Suporte a `X-RequestDigest` no cliente REST web para chamadas POST.

## Travamento por configuracao

A escrita continua desabilitada por padrao. Para teste manual supervisionado, configurar:

```env
VITE_ENAC_HABILITAR_ESCRITA_REQUISICAO_V30B=true
VITE_ENAC_MODO_TESTE_WEB_V30B=true
VITE_ENAC_CONFIRMACAO_MANUAL_V30B=CONFIRMAR-ESCRITA-WEB-V3.0B-ENAC
VITE_ENAC_SHAREPOINT_SCOPE=https://enaccombr.sharepoint.com/AllSites.Write
```

O aplicativo Microsoft Entra usado no navegador precisa ter permissao delegada de escrita compatível. O aplicativo readonly de inventario nao deve ser usado para este teste.

## Pre-validacao do host web

O host web bloqueia a escrita antes do componente operacional quando:

- `VITE_ENAC_ENTRA_CLIENT_ID` ainda aponta para o aplicativo readonly `ENAC-PnP-Inventario-SharePoint-Readonly-V2.3A`;
- `VITE_ENAC_SHAREPOINT_SCOPE` permanece em `AllSites.Read`;
- o modo de teste V3.0b nao esta habilitado;
- a confirmacao manual nao e exatamente `CONFIRMAR-ESCRITA-WEB-V3.0B-ENAC`.

Quando houver bloqueio, a tela exibe o motivo e continua em leitura/simulacao local, sem tentativa de POST.

## Fora do escopo

- Power Automate.
- Criacao ou alteracao de listas, colunas ou permissoes.
- Escrita de cotações, aprovações, pedidos, notas ou pagamentos.
- Carga real de dados operacionais sem marcador de teste.

## Observacao operacional

Sem as flags V3.0b, a tela pode continuar permitindo a simulacao local do prototipo, mas exibe aviso de que nada foi gravado nas listas.
