# V3.16 - Seed Realista de Homologacao

## Objetivo

Preparar o ERP ENAC para homologacao local controlada com massa de dados realista, sem dados sensiveis reais e sem qualquer integracao externa.

Marcador da massa:

```text
DEV_LOCAL_HOMOLOGACAO_ENAC_V316
```

## Como executar

```powershell
cd "C:\Users\leon\OneDrive - enac.com.br\Documentos\Sistema ENAC\server"
npm.cmd run seed:homologacao
npm.cmd run smoke:homologacao
```

## Dados criados

- Usuarios de homologacao para Diretoria, Planejamento, Compras, Financeiro, Campo e Admin.
- Clientes simulados: industrial, tecnologia retrofit, centro medico, condominio logistico e cliente teste.
- Fornecedores simulados: eletrico, hidraulico, concreto, aco, esquadrias, mao de obra, locacao e servicos tecnicos.
- Centros de custo para matriz, obra, materiais, mao de obra, equipamentos, terceiros, administrativo, financeiro e faturamento.
- Obras simuladas, com uma obra principal usada no fluxo completo.
- Contrato ativo, aditivo aprovado, orcamento aprovado e planejamento executivo ativo.
- Fluxo de compras com solicitacao, cotacao, mapa comparativo e pedido confirmado.
- Nota fiscal de entrada, conta a pagar, programacao, liberacao, conferencia e baixa manual simulada.
- Medicao, pedido de faturamento e faturamento manual informativo.
- Dados para previsto x realizado, dashboard executivo, riscos, tarefas, auditoria e documentos mockados.

## Idempotencia

A seed usa codigos deterministicos e `upsert`/busca previa antes de inserir. Ela pode ser reexecutada sem duplicar indevidamente os registros centrais.

## Limites

- Nao executa pagamento.
- Nao cria CNAB.
- Nao conecta banco real.
- Nao emite NFS-e real.
- Nao integra prefeitura.
- Nao gera boleto real.
- Nao faz upload externo.
- Nao usa SharePoint, Graph, Entra ou Power Automate reais.
- Nao usa `DELETE` fisico.

## Observacao sobre baixa manual

A massa inclui uma baixa manual simulada e marcada localmente para validar relatorios e roteiros. Ela nao representa pagamento real, liquidacao bancaria ou integracao externa.
