## Escopo Validado

O fluxo demonstrou a passagem controlada de uma requisicao de compra de teste por aprovacao, pedido, nota fiscal e programacao financeira.

Todos os registros foram restritos a marcadores `V2.7A-TESTE` e dependem das travas V2.7A:

- flags explicitas;
- modo teste;
- marcador obrigatorio;
- pre-validacao especifica;
- confirmacao manual;
- ausencia de escrita automatica no carregamento.

## Fora Do Escopo Ainda Nao Homologado

- Producao ampla.
- Fluxo com dados reais nao marcados como teste.
- Evolucao de pedido para enviado/entregue.
- Evolucao de NF para aprovada para pagamento.
- Pagamento efetivo.
- Data de pagamento.
- Comprovante.
- Envio para contabilidade.
- Power Automate.
- Permissoes finais de producao para todos os perfis reais em operacao ampla.

## Pronto Para Homologacao Assistida

Pode seguir para homologacao assistida controlada:

- o roteiro ponta a ponta de compra;
- as travas de teste;
- a rastreabilidade por historico;
- a validacao de listas reais do tenant;
- a revisao manual de registros criados.
