# V3.0A - Teste web com Entra e listas SharePoint

Objetivo: testar o Sistema ENAC fora de uma webpart SPFx, mantendo a estrutura React/modelos/repositório já desenvolvida.

## O que foi preservado

- Componente principal `EnacSistema`.
- Modelos de dados em `src/webparts/enacSistema/models.ts`.
- Repositório SharePoint com mapeamento das listas reais.
- Webpart SPFx existente, para comparação e rollback.

## O que foi adicionado

- Host web em `web/` com Vite.
- Login Microsoft Entra via `@azure/msal-browser`.
- Cliente HTTP `SharePointFetchClient`, que injeta token Bearer nas chamadas REST do SharePoint.
- Contrato `IEnacRepository`, removendo o acoplamento do componente React ao SPFx.

## Configuração local

1. Copie `web/.env.example` para `web/.env.local`.
2. Preencha:
   - `VITE_ENAC_ENTRA_CLIENT_ID=0dab19b3-8e48-4f89-ad94-1446b08d3781`
   - `VITE_ENAC_ENTRA_TENANT_ID=enaccombr.onmicrosoft.com`
   - `VITE_ENAC_SHAREPOINT_SITE_URL=https://enaccombr.sharepoint.com/sites/Equipe.Obras`
   - `VITE_ENAC_REDIRECT_URI=http://localhost:5173/`
3. No Microsoft Entra, registre uma SPA com redirect URI:
   - `http://localhost:5173/`
   - `http://localhost:5173`
   - `http://127.0.0.1:5173/`, opcional para testes abrindo o endereco por IP local
   - `http://127.0.0.1:5173`, opcional para testes abrindo o endereco por IP local
   - `https://sistema-enac.netlify.app`
4. Conceda escopo delegado compatível com SharePoint REST. Por padrão o host usa:
   - `https://enaccombr.sharepoint.com/AllSites.Read`

## Erro AADSTS50011

Se aparecer `AADSTS50011` informando que `http://127.0.0.1:5173` nao corresponde as redirect URIs configuradas, ha duas correcoes validas:

1. Abrir o app local por `http://localhost:5173`, mantendo `http://localhost:5173` cadastrado como SPA redirect URI.
2. Cadastrar tambem `http://127.0.0.1:5173` no app registration do Microsoft Entra.

O host web tambem aceita `VITE_ENAC_REDIRECT_URI` para forcar a URI enviada ao Entra. Em desenvolvimento local, quando aberto por `127.0.0.1`, o fallback passa a usar `http://localhost:5173/` para reduzir conflito com o cadastro documentado.

## Erro AADSTS9002326

Se aparecer `AADSTS9002326: Cross-origin token redemption is permitted only for the 'Single-Page Application' client-type`, a URI usada pelo navegador precisa estar cadastrada na plataforma correta:

- Plataforma: `Aplicativo de pagina unica` / `Single-page application`.
- URI local preferencial: `http://localhost:5173/`.
- Nao cadastrar essa URI apenas em `Web`.
- Se houver a mesma URI duplicada em outra plataforma, remover da plataforma incorreta e manter em SPA.

Depois de salvar a configuracao no Entra, limpe o estado de login do navegador ou abra uma janela nova e acesse novamente `http://localhost:5173/`.

## Observações de segurança

- O host web nasce em modo readonly.
- As flags de escrita controlada não são habilitadas no bootstrap web.
- Os cadastros e solicitacoes criados nas telas herdadas do prototipo ainda alteram apenas estado em memoria quando nao usam uma acao operacional controlada ja implementada.
- A conexao com listas SharePoint na V3.0A serve para leitura readonly de usuarios, alcadas, requisicoes, historico e diagnostico.
- Persistencia real de novos cadastros/solicitacoes na web exige uma rodada propria com permissao delegated de escrita, confirmacao de escopo Entra e mapeamento dos campos reais de cada lista.
- Para escrita futura, criar rodada própria e escopo Entra/SharePoint explícito, mantendo confirmação manual e marcadores de teste.

## Status de persistencia na web

O portal agora exibe um aviso no topo do modulo operacional:

- `Conectado as listas SharePoint em modo leitura`: a leitura funcionou, mas botoes comuns do prototipo nao gravam listas.
- `Falha ao ler listas SharePoint`: a web caiu para fallback local e nada sera salvo no SharePoint.
- `Modo local/prototipo`: nao ha reposititorio SharePoint ativo para aquela sessao.

A V3.0A nao deve ser interpretada como liberacao de escrita ampla. Escrita real deve ser tratada em V3.0B ou posterior, com app registration adequado e sem reutilizar o aplicativo readonly como se fosse app de gravacao.
