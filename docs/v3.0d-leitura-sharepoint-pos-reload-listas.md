# V3.0D - leitura SharePoint apos reload nas listas da interface

## Objetivo

Corrigir a situacao em que dados gravados ou existentes no SharePoint apareciam na lista fisica, mas a interface voltava para dados locais apos reload.

Esta etapa amplia a correcao aplicada em Requisicoes para as bases cadastrais ja exibidas diretamente na interface web/SPFx.

## Listas cobertas

| Tela da interface | Fonte SharePoint | Uso apos reload |
| --- | --- | --- |
| Clientes | `Lista 01 - Controle de Obras ENAC` | Clientes derivados do campo `Cliente` das obras reais |
| Obras | `Lista 01 - Controle de Obras ENAC` | Obras reais substituem a lista local inicial |
| Fornecedores | `Lista 06 - Fornecedores e Prestadores` | Fornecedores reais substituem a lista local inicial |
| Requisicoes | `Lista 02 — Requisições de Compra` | Requisicoes reais carregadas por `listarSolicitacoes()` |
| Administracao / Usuarios | `ENAC Usuarios Perfis` | Ja carregada em readonly |
| Administracao / Alcadas | `ENAC Alcadas` | Ja carregada em readonly |
| Historico administrativo | `ENAC Historico Configuracoes` | Ja carregado quando disponivel |

## Ajuste tecnico

- `IClienteCadastroEnac` e `IFornecedorCadastroEnac` passaram para `models.ts`, permitindo uso compartilhado entre componente e repositorio.
- `IEnacRepository` passou a expor `listarFornecedores()`.
- `SharePointEnacRepository` passou a ler a `Lista 06 - Fornecedores e Prestadores` via GET.
- O carregamento readonly da interface passou a atualizar:
  - `clientes`, derivados das obras reais;
  - `obrasCadastradas`, com a Lista 01 real;
  - `fornecedores`, com a Lista 06 real;
  - `solicitacoes`, com a Lista 02 real.

## Campos usados em fornecedores

Consulta readonly:

- `Id`
- `Title`
- `NomeFantasia`
- `CNPJ_x002f_CPF`
- `ContatoPrincipal`
- `Telefone_x002f_WhatsApp`
- `E_x002d_mail`
- `DadosBanc_x00e1_rios`
- `StatusdoFornecedor`

## Limites desta etapa

Nao foram criadas novas telas para Listas 03, 04, 08, 09 ou 10. Essas listas existem no tenant e seguem mapeadas, mas a V3.0D nao amplia o fluxo visual nem cria grids operacionais novos.

Nao houve:

- escrita no SharePoint;
- `POST`, `PATCH`, `MERGE` ou `DELETE` novos;
- alteracao de permissao;
- alteracao de listas ou colunas;
- Power Automate;
- alteracao no prototipo V2.2.
