Data: 2026-06-05

Branch: `dev/v2.3-sharepoint-integracao`

Commit base: `a00ec7b docs: preparar validacao manual readonly no tenant v2.4d`

## Objetivo

Gerar pacote SPFx production/SHIP local para validacao manual controlada no tenant, mantendo a webpart em modo readonly.

Codex nao conectou ao SharePoint, nao publicou pacote, nao instalou app, nao adicionou webpart em pagina, nao alterou listas, permissoes ou dados e nao iniciou Power Automate.

## Diferenca entre DEBUG e SHIP

Na V2.4D foi gerado pacote DEBUG local. Esse pacote serviu para testar o empacotamento, mas nao era o artefato ideal para validacao manual real no App Catalog porque podia depender de assets nao empacotados para uso autonomo.

Na V2.4E foi gerado pacote SHIP com assets client-side incluidos no `.sppkg`, mais adequado para upload manual controlado em App Catalog/site de teste.

## Sanitizacao do fallback local da webpart

Durante a validacao do pacote SHIP, a varredura identificou e-mails `@enac.com.br` embutidos no JS por causa dos dados mock/fallback da webpart SPFx.

Para evitar envio de e-mails reais no pacote, os e-mails mockados em `src/webparts/enacSistema/components/EnacSistema.tsx` foram trocados para o dominio reservado `example.invalid`.

Essa alteracao nao toca o prototipo homologado V2.2, nao altera `src/prototype/app.js`, nao altera regras de negocio e nao adiciona escrita. A leitura real do SharePoint continua usando os dados do tenant via repository readonly.

## Uso manual recomendado

Leon deve usar o pacote SHIP mais recente em uma validacao restrita:

1. abrir App Catalog ou area autorizada de apps;
2. fazer upload manual do `.sppkg`, se aprovado;
3. instalar/disponibilizar somente em site de teste;
4. adicionar a webpart em pagina controlada;
5. abrir console do navegador;
6. validar logs readonly `[ENAC][V2.4C]`;
7. conferir Network e confirmar ausencia de `POST`, `MERGE`, `PATCH` e `DELETE` gerados pela webpart;
8. remover webpart da pagina se houver erro relevante.

## Criterios de parada

- Erro de permissao de leitura.
- Erro de renderizacao.
- Erro JavaScript recorrente.
- Qualquer tentativa de escrita.
- Alteracao visual indevida.
- Necessidade de permissao alem de leitura para validar esta etapa.

## Recomendacao

O pacote SHIP esta pronto para validacao manual controlada no tenant, desde que Leon execute a publicacao manual em pagina restrita e interrompa se houver qualquer comportamento fora do modo readonly.
