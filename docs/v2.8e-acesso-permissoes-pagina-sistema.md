# V2.8E - Acesso E Permissoes Da Pagina Sistema ENAC

Data: 2026-06-09

## Objetivo

Definir a recomendacao de acesso para a pagina dedicada `Sistema ENAC - Homologação`.

## Principio

A pagina deve ser usada como aplicacao. Usuarios finais devem conseguir abrir e usar o sistema, mas nao editar a pagina moderna do SharePoint nem configurar a webpart.

## Grupos Sugeridos

- `ENAC Sistema Admin`;
- `ENAC Diretoria`;
- `ENAC Planejamento`;
- `ENAC Compras Financeiro`;
- `ENAC Campo`;
- `ENAC Leitura`.

## Permissoes Recomendadas

Usuarios finais:

- leitura/uso da pagina;
- sem permissao de editar pagina;
- sem permissao de publicar pagina;
- sem permissao de configurar webpart.

Administradores:

- Leon/Admin;
- editar pagina;
- publicar pacote;
- configurar webpart;
- validar propriedades operacionais;
- executar scripts manuais autorizados.

## Protecao Interna Do Sistema

Mesmo com acesso de leitura a pagina, a webpart continua validando a regra interna por:

- `ENAC Usuarios Perfis`;
- usuario ativo/inativo;
- perfil principal;
- permissoes funcionais;
- alçadas;
- status do processo;
- flags de escrita operacional;
- marcador de teste quando aplicavel.

## Observacoes Sobre SharePoint

Uma Single Part App Page reduz a aparencia de pagina comum, mas nao deve ser entendida como remocao total de todo chrome global do Microsoft 365.

As opcoes de edicao da pagina desaparecem para usuarios sem permissao de edicao. Se um usuario final ainda vir comandos de edicao, revisar permissao da pagina, biblioteca `Site Pages` e grupos herdados.

## Fora Do Escopo

- Power Automate;
- alteracao de listas;
- alteracao de dados;
- permissao final de producao ampla;
- remocao por script/hack de elementos globais do SharePoint.
