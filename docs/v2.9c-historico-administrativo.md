# V2.9C - Historico Administrativo

Toda escrita administrativa V2.9C deve registrar item em `ENAC Historico Configuracoes`.

## Campos usados

- `Title`: marcador `V2.9C-ADMIN-TESTE`, acao, lista e item.
- `TipoConfiguracao`: acao administrativa.
- `AcaoRealizada`: acao administrativa.
- `ItemConfiguracaoId`: lista alvo e item afetado.
- `ValorAnterior`: JSON sanitizado do item carregado pela tela antes da escrita.
- `ValorNovo`: JSON do payload enviado.
- `Justificativa`: justificativa informada, executor, perfil, resultado e observacao sobre snapshots.

## Regras

- Historico e registrado apos a escrita administrativa principal.
- Se a escrita principal falhar, a resposta retorna bloqueio/erro e nao registra historico como se houvesse sucesso.
- Para alcadas, o historico registra que alteracoes futuras nao alteram snapshots ja gravados.
- O historico deve ser conferido manualmente no primeiro teste controlado no tenant.
