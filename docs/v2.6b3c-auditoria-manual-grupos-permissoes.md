# V2.6B.3C - Auditoria Manual de Grupos e Permissoes

Data: 2026-06-08

Branch: `dev/v2.3-sharepoint-integracao`

## Objetivo

Preparar uma auditoria manual orientada para Leon conferir diretamente no SharePoint os grupos planejados, permissoes atuais do site e heranca das listas administrativas, sem aplicar nenhuma alteracao no tenant.

## Motivo

A auditoria conectada readonly V2.6B.3 confirmou a existencia das quatro listas administrativas, mas `Get-PnPGroup` retornou `Access is denied`. Por isso, os grupos planejados ficaram `NAO_CONFIRMADO` no relatorio gerado.

A verificacao manual e necessaria antes de qualquer aplicacao real de permissoes para confirmar:

- se os grupos planejados existem;
- se os nomes estao corretos;
- se ha usuarios individuais com permissao direta;
- se as listas administrativas ainda herdam permissoes do site;
- se existe algum risco antes de quebrar heranca.

## Escopo

Esta etapa e somente de observacao e registro. Leon nao deve criar grupos, alterar membros, quebrar heranca, conceder/remover permissoes ou editar listas durante esta auditoria.

Codex nao conecta ao SharePoint, nao executa script 11, nao usa `-Apply`, nao aplica permissoes, nao altera tenant e nao inicia Power Automate.

## Telas do SharePoint

Leon deve abrir:

`https://enaccombr.sharepoint.com/sites/Equipe.Obras`

Depois acessar:

1. Configuracoes do site.
2. Permissoes do site.
3. Configuracoes avancadas de permissoes, ou tela equivalente em portugues.

Para listas administrativas:

1. Abrir a lista.
2. Configuracoes da lista.
3. Permissoes para esta lista.
4. Verificar se a lista herda permissoes do site ou usa permissao unica.

## Grupos planejados

Verificar manualmente:

- ENAC Sistema Admin
- ENAC Diretoria
- ENAC Planejamento
- ENAC Compras Financeiro
- ENAC Cotacoes Contratos
- ENAC Campo Engenharia
- ENAC Leitura Auditoria

Registrar somente:

- `EXISTE`;
- `AUSENTE`;
- `NOME_DIFERENTE`;
- `NAO_VERIFICADO`;
- quantidade de membros, se visivel;
- observacao curta, sem e-mails.

## Listas administrativas

Verificar manualmente:

- ENAC Usuarios Perfis
- ENAC Alcadas
- ENAC Historico Configuracoes
- ENAC Snapshots Regras

Registrar somente:

- `HERDA`;
- `PERMISSAO_UNICA`;
- `NAO_VERIFICADO`;
- grupos/papeis principais visiveis, sem nomes pessoais desnecessarios;
- observacao curta.

## Relatorio seguro

O relatorio manual sera seguro para versionamento se nao contiver:

- e-mails;
- tokens;
- codigos de autenticacao;
- dados de itens;
- nomes pessoais desnecessarios;
- fornecedores;
- anexos;
- dados bancarios ou financeiros.

Preferir status, quantidade e observacoes objetivas.

## Criterios para decidir proxima etapa

Seguir para aplicacao real controlada somente se:

- grupos planejados existirem ou houver decisao formal de cria-los;
- nao houver usuarios individuais indevidos com permissao administrativa direta;
- as listas administrativas estiverem mapeadas;
- Leon aprovar textualmente a aplicacao real;
- rollback estiver documentado.

Se grupos estiverem ausentes, decidir entre criacao manual ou script protegido especifico. Se houver permissoes incoerentes, ajustar o plano antes de qualquer `Apply`.
