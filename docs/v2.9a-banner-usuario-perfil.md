# V2.9A - Banner Usuario E Perfil

## Decisao

O banner nao deve permitir escolha de identidade. O nome do usuario deve vir do contexto Microsoft 365 e aparecer como informacao fixa.

O seletor representa apenas o perfil de acesso autorizado para aquele usuario.

## Implementacao

O banner agora exibe:

- `Usuário`: nome fixo tratado visualmente;
- `Perfil de acesso`: seletor limitado aos perfis do cadastro interno.

Regras aplicadas:

- se houver apenas um perfil autorizado, o seletor fica desabilitado;
- se houver multiplos perfis autorizados, o usuario pode alternar apenas entre eles;
- se o usuario nao estiver cadastrado ou estiver inativo, a interface mostra alerta e bloqueia a selecao;
- `V2.3B-TESTE -`, `usr-` e `USR-` continuam removidos apenas visualmente.

## Homologacao

Durante a homologacao, a troca de perfil pode existir para usuarios com multiplos perfis autorizados. Para producao ampla, Campo nao deve escolher Diretoria e Compras nao deve escolher Administrador.
