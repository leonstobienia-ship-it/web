# V3.4B - Cotacao e Mapa Comparativo ERP ENAC

## Objetivo

A V3.4B implementa o modulo local de Cotacao e Mapa Comparativo do ERP ENAC. A etapa permite registrar propostas recebidas de fornecedores para uma Solicitacao de Compra em analise, comparar valores por item e selecionar uma cotacao no mapa.

Esta etapa usa somente PostgreSQL local `enac_erp_dev`. Nao ha SharePoint, Entra, automacoes, banco de producao, `DELETE` fisico, pedido de compra, nota fiscal, financeiro ou aprovacao por alcada.

## Status de cotacao

Status controlados:

- `RASCUNHO`
- `RECEBIDA`
- `DESCLASSIFICADA`
- `SELECIONADA`
- `CANCELADA`

Fluxos implementados:

- Criacao de cotacao ja como `RECEBIDA`.
- `RASCUNHO -> RECEBIDA`, reservado para evolucao local.
- `RASCUNHO | RECEBIDA -> DESCLASSIFICADA`.
- `RECEBIDA -> SELECIONADA`.
- `RASCUNHO | RECEBIDA -> CANCELADA`.

Selecionar uma cotacao nao cria pedido de compra. Pedido de compra fica para V3.4C.

## Validacoes

A API valida:

- UUIDs de empresa, solicitacao, fornecedor, cotacao e itens.
- Solicitacao existente e pertencente a empresa.
- Solicitacao em status `EM_ANALISE` para criar, editar ou selecionar cotacao.
- Fornecedor ativo e pertencente a empresa.
- Uma cotacao por fornecedor por solicitacao.
- Cotacao deve conter exatamente todos os itens ativos da solicitacao.
- `valor_unitario >= 0`.
- Quantidade herdada dos itens da solicitacao.
- Total do item calculado pela API.
- Total da cotacao calculado pela API.
- Edicao bloqueada para `DESCLASSIFICADA`, `SELECIONADA` e `CANCELADA`.
- Transicoes ilegais retornam `409`.

Erros:

- `400` para payload invalido.
- `404` para ID inexistente.
- `409` para duplicidade ou conflito de status.
- `503` apenas para falha real de banco.

As queries usam parametros do `pg`; nao ha concatenacao SQL com entrada de usuario.

## Frontend

Area criada:

- `web/src/features/cotacoes`

Menu criado:

- `Cotações`

Recursos:

- Selecao de solicitacao.
- Registro de cotacao por fornecedor.
- Edicao de cotacao recebida.
- Comparacao por item.
- Destaque de menor valor por item e menor total.
- Selecao de cotacao.
- Desclassificacao de cotacao.
- Estados de carregamento, vazio, erro e salvamento.
- Bloqueio de nova cotacao quando a solicitacao nao esta em `EM_ANALISE`.

- cria duas cotacoes com dois fornecedores;
- valida o mapa comparativo;
