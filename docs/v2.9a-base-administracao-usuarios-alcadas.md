# V2.9A - Base De Administracao De Usuarios E Alcadas

Data: 2026-06-10

Branch: `dev/v2.3-sharepoint-integracao`

## Objetivo

Preparar a base funcional de administracao de usuarios, perfis/categorias e alcadas, sem executar escrita real no tenant.

## Entregas

- Script readonly para auditar `ENAC Usuarios Perfis` e `ENAC Alcadas`.
- Banner ajustado para separar usuario fixo e perfil de acesso autorizado.
- Menus administrativos ocultos para usuarios fora do perfil `AdministradorSistema`.
- Tela de usuarios com UI preparada para `CriarUsuarioSistema` e `AtualizarUsuarioPerfilStatus`.
- Tela de alcadas com UI preparada para `AtualizarAlcadaUsuario`.
- Contratos administrativos iniciais em modelo TypeScript.

## Escrita Administrativa

Permanece bloqueada nesta versao.

Acoes futuras preparadas, mas nao executadas:

- `CriarUsuarioSistema`;
- `AtualizarUsuarioPerfilStatus`;
- `AtualizarAlcadaUsuario`;
- `RegistrarHistoricoAdministrativo`.

Todas deverao exigir:

- perfil `AdministradorSistema`;
- schema confirmado por auditoria readonly;
- pre-validacao;
- confirmacao manual;
- registro em historico;
- bloqueio se usuario atual nao for administrador.

## Preservacao Funcional

Nao houve alteracao em fluxos operacionais ja validados de requisicao, aprovacao, pedido, nota fiscal ou programacao de pagamento. Payloads, chamadas REST operacionais, travas V2.6A/V2.7A e scripts de limpeza foram preservados.

Power Automate permanece fora do escopo.
