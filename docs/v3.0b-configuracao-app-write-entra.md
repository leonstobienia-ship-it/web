## Redirect URI

A autenticacao do app write falhou com:

`AADSTS500113: No reply address is registered for the application.`

URI necessaria para o portal local:

```text
http://localhost:5173/
```

Essa URI deve ser cadastrada no app `ENAC Sistema - Write V3.0b` em:

`Authentication` -> `Add a platform` -> `Single-page application`.

Nao usar plataforma `Web` para esta URI do host Vite/MSAL.
