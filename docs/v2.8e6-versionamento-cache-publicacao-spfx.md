# V2.8E6 - Versionamento de pacote e validacao de cache SPFx

## Contexto

Apos publicacao manual do pacote das rodadas V2.8E4/V2.8E5, a pagina continuou visualmente igual. Antes de novas tentativas de CSS, a V2.8E6 cria uma versao inequivocamente nova do pacote para distinguir problema de cache/publicacao de problema de layout/canvas SharePoint.

## Versoes

| Artefato | Antes | Depois | Observacao |
| --- | --- | --- | --- |
| `config/package-solution.json` - `solution.version` | `1.0.0.0` | `1.0.0.1` | Incremento para App Catalog reconhecer novo pacote |
| `config/package-solution.json` - feature version | `1.0.0.0` | `1.0.0.1` | Mantido compatível com a solucao |
| `src/webparts/enacSistema/EnacSistemaWebPart.manifest.json` - `version` | `*` | `*` | Mantido conforme scaffold; o manifest usa a versao do `package.json` |
| `package.json` - `version` | `0.0.1` | `0.0.1` | Nao alterado, pois o versionamento de distribuicao SPFx do projeto esta em `package-solution.json` |

O manifest preserva `supportedHosts` com `SharePointWebPart` e `SharePointFullPage`, alem de `supportsFullBleed: true`.

## Marcadores visuais

Foram adicionados dois marcadores visiveis no cabecalho da webpart:

- `UI V2.8E6`;
- `Layout: full viewport ativo`.

Esses marcadores nao dependem de perfil especifico e nao usam dados operacionais. Eles servem apenas para diagnosticar se a versao publicada foi realmente carregada no tenant.

Interpretacao:

- se `UI V2.8E6` nao aparecer, o pacote/app/cache ainda nao atualizou;
- se `UI V2.8E6` aparecer e o layout continuar estreito, a versao nova carregou e o limite provavelmente esta no canvas/coluna/iframe do SharePoint ou em wrapper externo fora do alcance do componente;
- os marcadores devem ser removidos antes de uma versao final de producao, se Leon decidir.

## CSS preservado

A V2.8E6 preserva o full viewport controlado aplicado na V2.8E4:

- root `.enacSistema` com `width: calc(100vw - 16px)`;
- `max-width: calc(100vw - 16px)`;
- margens relativas ao viewport;
- `overflow-x: hidden` no root;
- tabelas com overflow interno;
- wrappers internos sem `max-width` limitante.

Nao foi usado CSS global para esconder elementos do SharePoint.

## Procedimento manual de publicacao e cache

1. Fazer upload/substituicao do pacote no App Catalog.
2. Confirmar que o App Catalog mostra a versao `1.0.0.1`.
3. No site `Equipe.Obras`, acessar `Conteudo do site` > `Aplicativos`.
4. Localizar o app do Sistema ENAC.
5. Clicar em `Atualizar`, se a opcao aparecer.
6. Aguardar alguns minutos.
7. Abrir a pagina em janela anonima:
   `/sites/Equipe.Obras/SitePages/Sistema-ENAC---Homologação.aspx?env=WebView`
8. Fazer `Ctrl+F5` ou `Ctrl+Shift+R` se necessario.
9. Confirmar se aparecem `UI V2.8E6` e `Layout: full viewport ativo`.
10. Validar se o painel esticou e se nao surgiu scroll horizontal global.
