## Erro Registrado No Dry-Run Manual

Leon executou manualmente o dry-run de:

`scripts/sharepoint/15-limpeza-dados-teste-controlada.ps1`

O dry-run nao excluiu itens, mas falhou ao ler todos os seis candidatos com erro de parameter set:

`Parameter set cannot be resolved using the specified named parameters.`

Os relatorios gerados em `reports/v2.8d-limpeza-dryrun.md` e `.json` devem ser considerados invalidos para autorizar limpeza.

## Causa Tecnica Provavel

A funcao de leitura por whitelist usava `Get-PnPListItem` combinando `-Query` e `-Fields`. Na versao PnP usada no ambiente do tenant, essa combinacao caiu em parameter set incompatível.

Como a limpeza controlada trabalha com IDs fixos em whitelist, a leitura correta e direta por ID.

## Correcao Aplicada

A funcao `Get-ItemByWhitelistEntry` foi alterada para usar:

```powershell
Get-PnPListItem -Connection $Connection -List $Entry.ListGuid -Id $Entry.ItemId -Fields $fieldList -ErrorAction Stop
```

A funcao agora retorna resultado estruturado com:

- `Ok`;
- `Item`;
- `Error`;
- `NotFound`.

O relatorio tambem passou a diferenciar:

- `LIDO_OK`;
- `ITEM_NAO_ENCONTRADO`;
- `TITLE_DIVERGENTE`;
- `MARCADOR_DIVERGENTE`;
- `APTO_PARA_LIMPEZA`;
- `BLOQUEADO`;
- `ERRO_LEITURA`.

## Resumo Do Relatorio

O relatorio corrigido inclui:

- total de itens whitelistados;
- total lido;
- total apto;
- total bloqueado;
- total erro;
- total nao encontrado;
- flag de dry-run sem limpeza;
- `AUTORIZACAO PARA EXECUCAO: NAO` quando houver qualquer erro ou bloqueio.

## Execucao Real

A execucao real permanece bloqueada. O comando com `-Execute` e token nao deve ser usado nesta rodada.

Somente depois de Leon enviar um dry-run limpo, sem erros e revisado manualmente, a limpeza real podera ser discutida em etapa propria.
