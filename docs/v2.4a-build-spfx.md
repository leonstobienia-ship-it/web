Rodada de migração controlada do scaffold SPFx mínimo para a raiz do projeto, sem conexão ao SharePoint, sem Power Automate, sem alteração de listas, permissões ou dados e sem integração funcional nova.

## Ajustes realizados

### package.json

O scaffold SPFx 1.23.0 foi mantido com React 17.0.1, TypeScript ~5.3.3 e Gulp 4.0.2.

Foi adicionada a dependência:

- `@microsoft/sp-http`: `1.23.0`

Motivo: `src/webparts/enacSistema/services/SharePointEnacRepository.ts` importa `SPHttpClient` e `SPHttpClientResponse`.

### Manifest

`src/webparts/enacSistema/EnacSistemaWebPart.manifest.json` foi ajustado para escopo SharePoint nesta fase:

- `componentType`: `WebPart`
- `alias`: `EnacSistemaWebPart`
- `title`: `Sistema ENAC`
- `description`: `Sistema ENAC`
- `supportedHosts`: `["SharePointWebPart"]`

Hosts Teams e arquivos `teams/*` não foram incluídos nesta rodada.

### skipFeatureDeployment

`config/package-solution.json` foi ajustado para:

```json
"skipFeatureDeployment": false
```

Decisão: preferir rollout controlado por site nesta etapa.

### EnacSistemaWebPart.ts

O wrapper do scaffold foi adaptado para renderizar o componente ENAC atual:

- importa `{ EnacSistema }` de `./components/EnacSistema`;
- passa `currentUserName` a partir de `this.context.pageContext.user.displayName`;
- usa `currentUserPerfil: "Campo"` como perfil inicial mínimo;
- não cria chamadas novas ao SharePoint;
- mantém apenas property pane simples do scaffold.

### tsconfig.json

Foi adicionado `es2015.core` em `compilerOptions.lib`.

Motivo: o componente e o repositório atuais usam `Array.find`, e o scaffold padrão não habilitava essa lib.

### .gitignore

Foram adicionados artefatos gerados pelo SPFx:

- `solution/`
- `lib-dts/`
- `coverage/`
- `.heft/`
- `*.scss.ts`

## Resultado dos comandos

### npm install

Resultado: concluído com sucesso.

Resumo:

- 1988 pacotes adicionados;
- `package-lock.json` criado;
- 75 vulnerabilidades reportadas por `npm audit` em dependências transitivas;
- vários avisos de pacotes depreciados.

Nenhum `npm audit fix` foi executado nesta rodada para evitar alterações amplas e potencialmente incompatíveis com SPFx.

### npx gulp clean

Resultado: concluído com sucesso.

Ambiente reportado:

- projeto `enac-sistema-spfx` versão `0.0.1`;
- build tools `3.19.0`;
- Node `v22.22.3`.

### npx gulp build

Primeira execução: falhou em TypeScript.

Erros principais:

- `Array.find` indisponível pelo `lib` do `tsconfig`;
- classes SCSS `active` e `row` usadas no componente, mas ausentes da tipagem gerada.

Correções feitas:

- adicionado `es2015.core` ao `tsconfig.json`;
- adicionadas classes `active` e `row` ao SCSS atual.

Segunda execução: concluída com sucesso.

Ambiente reportado:

- projeto `enac-sistema-spfx` versão `0.0.1`;
- build tools `3.19.0`;
- Node `v22.22.3`;
- duração total aproximada `3.69 s`.
