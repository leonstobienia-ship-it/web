# V3.2 - Modelo Inicial PostgreSQL

## Objetivo

Registrar o primeiro desenho relacional do ERP ENAC para desenvolvimento local/controlado. A migration `database/migrations/001_init_core.sql` nao foi executada contra producao e nao deve ser aplicada em banco real sem revisao tecnica, backup, ambiente isolado e aprovacao formal.

## Convencoes

- Chaves primarias usam `uuid` com `gen_random_uuid()`.
- Tabelas principais possuem `status`, `created_at`, `updated_at`, `created_by` e `updated_by`.
- Tabelas operacionais carregam `company_id` para multi-CNPJ.
- `obra_id` e `centro_custo_id` aparecem onde existe contexto operacional ou financeiro.
- `documentos` guarda metadados e vinculos; o binario permanece em SharePoint.

## Tabelas

| Tabela | Finalidade |
|---|---|
| `empresas` | CNPJs, matriz/filial e dados fiscais basicos |
| `usuarios` | Usuarios internos vinculados ao Entra ID |
| `perfis` | Papeis de aplicacao e permissoes |
| `clientes` | Clientes, locatarios e partes a receber |
| `fornecedores` | Fornecedores, prestadores e dados de pagamento |
| `obras` | Obras/projetos vinculados a empresa, cliente e centro de custo |
| `centros_custo` | Estrutura de custos e contas analiticas |
| `contratos_cliente` | Contratos de obra, servico ou locacao com clientes |
| `contratos_fornecedor` | Contratos de prestadores e fornecedores |
| `solicitacoes_compra` | Necessidades de compra/servico originadas da operacao |
| `cotacoes` | Propostas de fornecedores por solicitacao |
| `pedidos_compra` | Pedido aprovado para fornecedor |
| `notas_fiscais` | Documentos fiscais recebidos ou emitidos |
| `contas_pagar` | Titulos a pagar e programacao financeira |
| `contas_receber` | Titulos a receber, cobranca e baixa futura |
| `medicoes_obra` | Medicoes tecnicas e financeiras por obra |
| `documentos` | Metadados de arquivos no SharePoint |
